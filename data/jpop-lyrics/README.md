# JPOP 가사 LRC 파일 폴더

이 폴더에 LRC 파일을 두면 앱이 자동으로 가사·타이밍을 로드합니다.

## 파일 이름 규칙

`{songId}.lrc` 형식으로 저장합니다. `songId`는 `src/lib/jpopSongs.ts`의 `JPOP_SONGS[].id` 와 동일합니다.

- `jpop-lemon.lrc`
- `jpop-pretender.lrc`
- `jpop-gunjo.lrc`
- `jpop-gurenge.lrc`

## LRC 포맷

표준 LRC와 동일한 `[mm:ss.xx]` 타임스탬프를 사용합니다. 본 앱은 한 가지 확장을 추가로 지원합니다:

```
[00:08.50]표시할 가사 줄|ひらがなのタイピング行
```

- `|` 왼쪽: 화면에 표시되는 가사 (한자/가나 자유)
- `|` 오른쪽: 타이핑 검증용 텍스트 (히라가나 권장 — `typingEngine`이 로마자/한글 후보를 자동 생성)
- `|`가 없으면 한 텍스트가 표시·타이핑 양쪽에 사용됩니다.

여러 타임스탬프를 한 줄에 묶어 후렴 반복을 표현할 수도 있습니다:

```
[00:34.20][01:48.30]繰り返しのサビ|くりかえしのさび
```

`example.lrc` 파일을 참고하세요 (저작권 없는 샘플 가사).

## 동작 우선순위

`{songId}.lrc` 파일이 존재하면 그 파일이 모든 인라인/DB 가사보다 우선합니다. 파일이 없으면 `jpopSongs.ts`의 `lyricLines` 인라인 데이터를 사용하고, 그것도 없으면 가사 없이 영상만 재생됩니다.

## 저작권 주의

상업 J-POP 곡의 가사는 저작권 보호 대상입니다. 이 폴더의 `.lrc` 파일은 기본적으로 `.gitignore`되어 있으니 정식 라이선스가 있거나 본인 작성/공개 도메인 가사인 경우에만 사용/공유해주세요.
